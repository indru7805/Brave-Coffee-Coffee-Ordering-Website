# Brew Haven – Coffee Shop Website

A responsive multi-page website for a coffee shop, with a menu, about and contact pages, and a registration page.

**Live preview:** https://indru7805.github.io/Brave-Coffee-Coffee-Ordering-Website/


## Features
- Home page with hero section, signature drinks (Classic Espresso, Cappuccino, Caramel Latte, Chocolate Mocha), gallery, and customer reviews
- Menu, About, Contact, and Registration pages
- Responsive layout for mobile and desktop

## Tech Stack
- Front end: HTML5, CSS3, Bootstrap
- [Back end: Python, Flask, MySQL]

## Getting Started
1. `git clone https://github.com/indru7805/Brave-Coffee-Coffee-Ordering-Website.git`
2. Open `index.html` in a browser for the front end.
3. [Backend steps: install requirements, create the MySQL database, run `python app.py`]
